# Stakeholder Responsibility Matrix (Illustrative)

**R = Responsible, A = Accountable, C = Consulted, I = Informed.** This is a proposed project-level RACI, not a claim about actual government-defined roles.

| Activity | Executive Sponsor | ISSM / GRC Lead | IT / Cloud Lead | Program / Contracts Lead | End Users |
|---|---|---|---|---|---|
| Approve program scope | A | R | C | C | I |
| Identify CUI contractual obligations | I | C | C | A/R | I |
| Map CUI system and security dependencies | I | A | R | C | C |
| Maintain asset inventory | I | A | R | C | C |
| Define risk assessment methodology | A | R | C | C | I |
| Implement technical safeguards | I | A | R | C | I |
| Approve risk treatment / acceptance | A | R | C | C | I |
| Report program status | A | R | C | C | I |

**RACI review point:** Confirm authority for contract interpretations and risk acceptance; neither is automatically delegated to the technical team.
