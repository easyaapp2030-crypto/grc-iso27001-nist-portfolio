# Framework Crosswalk — Method and Guardrails

This directory will contain the Day 4 mapping work. The mapping must identify the **actual primary requirement**, then document related outcomes or controls as references without implying one-to-one equivalence.

- **NIST SP 800-171 / CMMC Level 2:** modeled contractor CUI requirements.
- **NIST SP 800-53 Rev. 5:** supplemental control references; 800-53 controls are not automatically contractually binding.
- **NIST CSF 2.0:** related cybersecurity outcomes.
- **ISO/IEC 27001:2022:** management system requirements and relevant Annex A themes; proprietary standards text should not be reproduced.

Document revision, scope, rationale, and limitations for every mapping. Where mappings are approximate or partial, label them explicitly. Do not claim CMMC certification, ISO certification, or an ATO.
