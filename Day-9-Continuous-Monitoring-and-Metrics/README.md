# Day 9 — Continuous Monitoring & Security Metrics

**Objective:** Build a repeatable security monitoring and leadership reporting model tied to Day 8 remediation.

## Files
- `Continuous_Monitoring_Strategy.md` — scope, owners, cadence, reporting and escalation.
- `Security_Metrics_Catalog.csv` — eight defined metrics with sources and limitations.
- `Monitoring_Action_Log.csv` — threshold-to-response mapping.
- `Monthly_Security_Scorecard.md` — leadership-ready reporting template.

**Cross-day traceability:** Day 7 findings → Day 8 POA&M → Day 9 metrics and response actions → Day 10 leadership decisions.

**Simulation:** No live telemetry, measured control effectiveness, or production monitoring is represented.
