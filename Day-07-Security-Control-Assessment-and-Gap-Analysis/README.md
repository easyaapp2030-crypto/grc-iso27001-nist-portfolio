# Day 7 — Security Control Assessment & Gap Analysis

**10-Day GRC Portfolio | Sentinel Defense Solutions (fictional DoD contractor)**

## Objective
Assess a sample of security controls using simulated evidence, document gaps, and propose corrective actions. This is a training exercise, not a real audit or CMMC assessment.

## Contents
- `Assessment_Methodology.md` — scope, approach, ratings and limitations
- `Control_Assessment_Workbook.csv` — 12 example control tests and results
- `Gap_Analysis.md` — summarized gaps and prioritization
- `Findings_and_Remediation_Register.csv` — ownership, actions and due-date placeholders

## How to use
1. Review Day 6 evidence requests and control implementation tracker.
2. Replace illustrative evidence with authorized, redacted evidence in a real-world exercise.
3. Execute tests, document evidence identifiers, and update ratings.
4. Route findings to the risk register and remediation workflow.

## Standards note
Example mappings are learning aids; verify applicability against the contract, system scope, and authoritative framework publications. CMMC Level 2 is based on NIST SP 800-171 Rev. 2 requirements; NIST SP 800-171 Rev. 3 is a distinct newer revision.

## Disclaimer
All organizations, systems, evidence, results, owners, and findings in this folder are fictional or simulated. No real control effectiveness has been validated.
